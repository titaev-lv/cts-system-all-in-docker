├── mysql/                           # MySQL Server & Clients
│   ├── server/

│   │   └── mysql.ext
│   └── clients/
│       ├── web-ui/
│       │   ├── mysql-client.key
│       │   └── mysql-client.crt
│       └── cts-core/
│           ├── mysql-client.key
│           └── mysql-client.crt
│
├── clickhouse/                      # ClickHouse Server & Clients (future)
│   ├── server/
│   └── clients/
│       ├── web-ui/
│       ├── trader-1/
│       ├── trader-2/
│       └── trader-3/
│
├── hsm-service/                     # HSM Service Server & Clients
│   ├── server/

│   │   ├── hsm-service.crt

│   └── clients/
│       ├── web-ui-2fa/              # OU=2FA
│       ├── cts-core-2fa/            # OU=2FA
│       ├── cts-core-trader/         # OU=Trader

    └── clients/
        ├── web-ui/
        ├── trader-1/
        ├── trader-2/
        └── trader-3/

## Certificates Overview

### Server Certificates (4 total)
- **mysql** - MySQL database server
- **clickhouse** - ClickHouse analytics database (future)
- **hsm-service** - HSM cryptographic service
- **cts-core** - CTS-Core orchestrator

### Client Certificates (16 total)

#### Database Clients (OU=Database)
- web-ui → MySQL
- cts-core → MySQL
- web-ui → ClickHouse
- trader-{1,2,3} → ClickHouse

#### HSM Clients
- web-ui → HSM (OU=2FA)
- cts-core → HSM (OU=2FA)
- cts-core → HSM (OU=Trader)
- trader-{1,2,3} → HSM (OU=Trader)

#### CTS-Core Clients
- web-ui → CTS-Core (OU=Admin)
- trader-{1,2,3} → CTS-Core (OU=Trader)

## ⚠️ Security Notes

- **DO NOT** commit key files to git (`.gitignore` enforced)
- All `.key` files must have permissions `600`
- CA private key requires special protection (restrict access)
- All files are auto-mounted read-only in containers

## Generation

All certificates are auto-generated by:
```bash
./init-system.sh
```

Or manually by PKI scripts:
```bash
scripts/pki/01-generate-ca.sh
scripts/pki/02-generate-server-certs.sh
scripts/pki/03-generate-client-certs.sh
```

## Regeneration

To regenerate all certificates (delete and recreate):
```bash
scripts/pki/clean-pki.sh
./init-system.sh  # or run PKI scripts manually
```
